📖 설정 방법

1
GPS Logger 설치
Play 스토어에서 "GPS Logger for Android" 검색 후 설치
Play 스토어 열기
2
Custom URL 설정
앱 실행 → ☰ 메뉴 → Logging details → Log to custom URL 켜기
3
URL 입력
위의 URL을 복사해서 붙여넣기
4
HTTP Method
PUT 으로 변경 (기본 POST → PUT)
5
HTTP Body
위의 Body를 복사해서 붙여넣기
6
HTTP Headers
Content-Type: application/json 추가
7
자동 시작 설정
☰ → General options → "Start on bootup" 켜기
→ "Start logging on app launch" 켜기
8
전송 간격 설정
☰ → Logging details → Time interval
권장: 15초~30초 (배터리와 정확도 균형)

💡 참고

  • GPS Logger는 화면 꺼져도 백그라운드에서 계속 작동합니다
  • 배터리 최적화에서 GPS Logger를 제외해주세요
  • child.html 페이지는 핑/SOS/가족위치 확인용으로 따로 사용 가능
  • 두 가지(웹+앱)를 동시에 쓰면 더 정확합니다
