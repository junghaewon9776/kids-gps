📱 사용 방법

1단계: 관리 페이지에서 부모 계정(ID+비번) 생성

2단계: 부모가 모니터링 페이지에서 로그인 → 자녀 등록(연락처)

3단계: 아이 폰에서 위치 전송 페이지 열고 → 연락처 입력하면 GPS 전송 시작

4단계: 부모 모니터링에서 실시간 위치 확인, 벨 울리기, 길찾기
